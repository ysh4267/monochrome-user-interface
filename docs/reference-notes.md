## 전체 스타일

- 흑백. 선·채움 #000, 면 #fff. 살 수 없는 값·설명은 회색(약 #6a6a6a), 잠긴 것은 옅은 회색(약 #cbcbcb).
- 선 굵기 3px(독·카드·버튼 링·다이얼로그), 2px(배지·꼬리표·선택기), 1px(행 구분선).
- 상자 모서리 5px, 독 28px, 알약 10~16px.
- 그림자는 번짐 없는 하드 섀도: 카드·다이얼로그는 오른쪽·아래 6px(큰 패널은 8px), 원형 버튼은 아래 6px. 밝기 약 205 → 검정 20%.
- 모달 뒤 흰 막: 검은 군중이 밝기 226으로 보임 → 흰색 88%.
- 글꼴: Noto Sans CJK(크레딧에 명시). 로고는 전용 그림.
- 커서: 회전문을 위에서 본 “(+)”, 누를 수 있는 곳에서는 “((×))”. 가운데 십자가 천천히 돎. 흰 테두리 있음.

## 아이콘

- 그리는 법: 같은 화면의 프레임 8~33장을 픽셀별 절사 평균으로 겹쳐 잡음을 없앤 뒤, 아이콘마다 도형 모델(예: 티켓 = 둥근 홈이 팬 사각 테두리 + 고리)을 세우고 블러를 건 렌더링과 원본의 차이가 가장 작아지도록 수치를 맞췄습니다. 맞춘 뒤 남는 오차(RMS)는 대부분 0.01~0.04 입니다.
- 글리프 상자(24 단위)가 화면에서 차지하는 크기: 독 버튼 42px, 계약 카드 76px, 환생 목록 26px, 칩 24px(진행 링 칩 26px), 진행 패널 표지는 원 지름의 0.54배.
- 아이콘은 상자 한가운데에 놓이지 않는 것이 있습니다(확성기는 오른쪽 아래로, 플라이휠은 왼쪽 위로 치우침). 원본의 치우침을 그대로 옮겼습니다.
- 소용돌이(스핀) 글리프는 소용돌이의 중심이 상자 중심이고 화살촉이 오른쪽으로 삐져나옵니다. 쓰이는 곳마다 크기가 다릅니다: 환생 버튼 47px, 환생 화면 머리 52px, 다시 개업 숫자 56px, 목록 22.5px, 값 배지 15px.
- 값 표시의 고리는 줄 상자가 아니라 숫자 높이에 맞춰 앉습니다. 가운데(환생) 값은 옆 버튼의 값보다 3px 위에 있고 글자가 작습니다(15px).
- 계약 카드: 간격 32px. 처음 열면 첫 장이 잡힌 상태(14px 떠오름 + 선 5px, 내용은 2px 밀림)입니다. 마우스를 올린 카드는 14px 떠오르되 선은 3px 그대로입니다.
